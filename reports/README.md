# Reports

Deney ve teknik raporlar buraya eklenir. Her raporda tarih, kapsanan dönem, kullanılan veri ve bilinen sınırlamalar bulunmalı. Özel mesaj içeriğini dışa aktaran raporlar yerel kalmalı; Git'e eklenmemeli.

`2026-11-14-public-release-readiness.md` tracks the public-repository and v0.1.0 desktop packaging work, including verification and remaining release limits.

`benchmark-*.md` and its JSON companion contain synthetic local performance baselines. They do not include private experiment records or call Codex. Each baseline names the Node runtime, machine, workload, correctness checks, route timings, and known load bottlenecks.
