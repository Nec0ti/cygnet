# Cygnet 1.1 / 2.0 doğrulama raporu

Tarih: 2026-11-13

## Kapsam

1.1 tarih aralıklı rapor, CSV güvenliği, kontrollü persona kohortları, deney karşılaştırması, salt okunur olay replay'i, profil araması/feed sıralaması ve persona prompt sınırları kontrol edildi.

## Sonuçlar

- JSON raporu; günlük ve persona bazında post, story, DM, beğeni, yorum, takip değişimi, report, görsel, görsel üretim hatası ve aktif persona sayılarını döndürüyor. Rapor, üretildiği andaki ayar snapshot'ını ve seçili aralıktaki event kayıtlarını içeriyor.
- CSV dışa aktarma aynı metrikleri veriyor; `=`, `+`, `-`, `@` ile başlayan hücreler ve başında boşluk olan formül hücreleri spreadsheet enjeksiyonuna karşı kaçışlanıyor.
- İzole API akışında 100 persona, JSON/CSV raporu, geçersiz tarih `400`, rapor aralığı, iki farklı kısa/ifadeci koşullu kohort, ayar/nüfus kilidi, kohort etkinlik sayımı, deney bitirme ve yeniden başlatma doğrulandı.
- Replay endpoint'i olayları zamana ve ID'ye göre sıralıyor; UI seçim/oynatımında olaylar tekrar işlenmiyor. Replay aralığı en fazla 5.000 olayla sınırlı.
- Arama ad, kullanıcı adı, bio, ülke ve pronouns üzerinde çalışıyor; feed yeni, en çok beğenilen ve en çok yorumlanan seçeneklerini sunuyor.
- Self-check'ler mevcut system.md içindeki profil kimliği, yaş, ülke, pronouns, ton ve trait alanlarını; 18 yaş altı cinsel içerik sınırını; yetişkin/yaşı bilinmeyen DM yönergelerini doğruluyor.
- `server/npm run check`, server JavaScript parse kontrolleri, `web/npm run build` ve `git diff --check` geçti.

## Sınırlar

- Bir haftalık gerçek kullanım verisi henüz toplanmadı. Araç hazır; gerçek yedi günlük sonuç için yerel simülasyonu bir hafta çalıştırıp sonrasında tarih aralıklı rapor üretmek gerekiyor.
- Tarayıcı görsel E2E'si çalıştırılmadı; ortamda Chromium/Firefox/Playwright bulunmuyor.
- Uçtan uca API veritabanı ve persona dosyaları `/tmp` altında oluşturulup silindi; kullanıcının `server/data` alanı kullanılmadı.
